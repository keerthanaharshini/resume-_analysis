# AI Resume Analyzer with AI Interview

An AI-powered Resume Analyzer built using Python, Streamlit, and Google Gemini.

## Features

- Upload Resume (PDF)
- Resume Skill Analysis
- Resume Score
- AI Technical Interview Questions
- AI Answer Evaluation
- Final Interview Score

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- pdfplumber
- python-dotenv

## Installation

```bash
pip install -r requirements.txt
```

Run the project:

```bash
streamlit run app.py
```
